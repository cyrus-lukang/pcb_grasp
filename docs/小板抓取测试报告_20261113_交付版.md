# 2. 实验协议

## 2.1 系列一 · 闭环抓取（001～004）

流程：头粗定 → camera-down 悬停 → 腕精定 → 末端 `(-90°,0,rz)` → 降至示教 tip 高度（grasp_z+1 cm ≈ 725.5 mm）→ 知行收夹。

成功判据：流程跑通且完成收夹；失败判据：运动规划/到位失败或未收夹。

## 2.2 系列二 · 定位供姿（005～011）

流程：头粗定与腕精定由本系统给出；末端目标位姿输出为可执行 CLI；运动由 `rim_python.move_to_pose` 执行（与系列一同一运控栈）。

精定位末端约定：

- XY：腕精板心  
- RPY：`(-90°, 0°, rz)`，rz 取精定位结果  
- Z：标定抓取高度 + 10 cm（grasp_z + 0.10 m ≈ **815.5 mm**）

误差分析指标（感知一致性，单位 mm / °）：

- Δxy = ‖(x,y)_fine − (x,y)_coarse‖₂  
- Δrz = unwrap(rz_fine − rz_coarse)

说明：Δxy / Δrz 度量**本系统粗定位相对精定位的偏差**，是供姿质量的核心指标；运动是否拆段执行不影响该指标定义。

# 4. 误差分析

## 4.1 系列一（001～004）闭环抓取

| 统计量 | 成功轮 001～003 | 全 4 轮 |
|-|-|-|
| Δxy (mm) | 7.4 / 11.5 / 10.3；均值 **9.7** | 另含 004 的 4.6 |
| Δrz (°) | +4.1 / −1.9 / −5.1；\|Δrz\| 均值 **3.7** | 004 为 +80.6（离群） |
| 抓取成功率 | **3/4 = 75%** | |

失败机理（004）：精定位 Δxy=4.6 mm（优），但 rz 相对粗定位跳变约 80°；下发抓取姿态时 MC 报 `PLAN_STATUS_CODE_FAILED arrive timeout`，TCP 几乎未完成姿态跟踪。归因：**运控短距/大姿态跟踪** + **精定位 rz 跳变**，不是粗定位选错板。

## 4.2 系列二（005～011）定位供姿

| 统计量 | 全部 7 轮 | 剔除 rz 跳变轮（\|Δrz\|≥40°，即剔除 006）后 6 轮 |
|-|-|-|
| Δxy (mm) | 41.6, 14.1, 13.2, 16.4, 15.2, 17.6, 17.5 | 均值 **20.3**（含 005）；若再剔除 005：均值 **15.7** |
| \|Δrz\| (°) | 3.5, 78.6, 8.4, 4.4, 2.7, 6.1, 4.9 | 均值 **5.0**（6 轮） |
| rz 跳变轮 | 006（+78.6°） | 与 004 同类，需门控 |

补充：

- **005**：Δxy=41.6 mm 显著偏大，同时腕深度给出异常板坐标 z；供姿法兰 Z 已按协议固定为 grasp_z+10 cm，故 Z 供姿不受该深度异常影响，但 XY 误差不可作为标称精度引用。  
- **007～011**：Δxy 稳定在 **13～18 mm**，\|Δrz\| 多数 **&lt;10°**，可作为当前配置下定位一致性参考区间。  
- 运动执行：目标位姿由本系统生成；执行侧观察到短位移可到位，单段约 0.2 m 量级易出现 arrive timeout，工程上需**拆段**或加大 duration/timeout。该问题属于运控跟踪，不改变上表感知误差定义。

## 4.3 综合

| 指标 | 数值 | 解读 |
|-|-|-|
| 闭环抓取成功率 | 75%（3/4） | 主链路可交付试用 |
| 标称粗→精 Δxy（稳定轮） | ≈16 mm（007～011） | 供姿前相对修正量级 |
| 标称粗→精 \|Δrz\|（稳定轮） | ≈5° | 可接受；&gt;25～40° 应拒抓 |

# 6. 方法与已知限制（摘要）

1. **感知**：头粗 + 腕精；精定位 rz 来自外轮廓匹配角；实现位于 `pcb_grasp` 调用 `TCT` 匹配库。  
2. **供姿**：系列二由本系统输出末端 xyzrpy，运动执行使用标准 `move_to_pose` CLI（可与 UI 解耦）。  
3. **运控**：中长位移单段易 arrive timeout；短位移验证可动；工程建议拆段。  
4. **失效模式**：粗精 \|Δrz\|≈80°（004、006）必须门控；005 腕深异常导致 Δxy 不可用。  
5. **未纳入本报告的内容**：大板双臂对挤；跨日板位绝对坐标对比。

# 7. 后续建议

1. 对 \|Δrz(粗,精)\| &gt; 阈值（建议 25°～40°）拒抓或回退粗 rz。  
2. 姿态大变化：先抬高再转 rz，再降 Z；或强制拆段 CLI。  
3. 将 match score / ok、腕深有效标志写入 `result.json`，便于正式统计。  
4. 在稳定板位下补 ≥20 轮，给出 Δxy / Δrz 分位数与抓取成功率置信区间。
