# ICT 小板感知定位方案

> 大板双臂夹持方案已拆至独立文档（见文末链接）。本文仅描述 PCB 小板单臂抓取的感知与供姿链路。

## 1. 方案概述

### 1.1 目标

面向 ICT 产线 PCB 小板单臂抓取，构建「全局检测 — 目标选择 — 腕部精定位 — 抓取点生成」的感知系统。系统以头部与腕部图像、深度、相机标定及机器人位姿为输入，将图像中的小板转换为运动模块可用的基座坐标目标，支撑：

- 场景识别：区分小板、空槽与大板；本方案只对小板进入抓取分支。
- 接近引导：在已知板面高度约束下计算粗位姿，引导腕部至目标上方观测。
- 精定位：近距离关键点检测与外轮廓匹配，确定板心与抓取方向，生成单臂抓取目标。
- 过程追溯：保留粗定位、精定位、目标关联与执行阶段结果，供误差分析与现场复盘。

小板流程为：**头部粗定位 → 腕部近距离检测 → 外轮廓匹配修正中心 → 抓取位姿生成**。

适用工况：已知高度、近似水平放置、关键点可见的 PCB。系统输出平面位置与方向，Z 由板面或示教高度约束。任意倾斜、堆叠目标的完整 6D 位姿估计不在本版本范围。

托盘搬运、MES 校验、空槽放置规划、提起后的持物验证等属于其他模块或后续扩展。

### 1.2 感知任务定义

| 项目 | 内容 |
|-|-|
| 头部检测类别 | pcb_small（class 0）；空槽/大板仅参与场景识别，不进入本方案抓取 |
| 头部定位 | 四角射线与已知板面求交 |
| 接近方式 | 将腕相机移至目标上方观测（camera-down） |
| 近距离精定位 | Gemini305 + YOLO-Pose + 外轮廓 Chamfer |
| 位置输出 | 轮廓匹配中心对应的基座 XY |
| 方向依据 | 轮廓匹配角（关键点作搜索初值）；执行侧末端 `(-90°, 0, rz)` |
| 高度来源 | 视觉 Z 用于定位；执行 Z 采用示教值及抬高量 |
| 执行动作 | 末端对准板心 → 下降 → 收夹 |

空槽 nopcb（class 1）参与头部场景检测与编号，其检出不等于完成放置规划。

### 1.3 精度、成功率与节拍

识别、定位与执行分开验收。检测置信度、轮廓匹配分数、运动到位容差均不直接等同于定位精度。抓取成功以实际持物结果判定。

| 指标 | 项目目标或口径 | 验证方式 |
|-|-|-|
| 类型识别 | >99.9% | 独立测试集：分类正确率、漏检、误检 |
| 角点 / 板心定位 | <5 mm | 基座坐标与独立测量真值比较 |
| 方向定位 | 旋转误差 <0.3°（口径需与项目统一） | 统计板边方向与执行方向误差 |
| 感知节拍 | 物料识别校验 ≤2 s | 明确取流、检测、深度与匹配计时范围 |
| 完整抓取 | 含视觉 ≤8 s | 端到端耗时；单独统计失败与重试 |

上述为目标对齐口径；已有真机证据见第 7 章。

### 1.4 系统边界

沿用项目分层架构，当前接入头部双目与左腕相机。小板执行头—腕两级定位。胸前融合、双腕精定位、多 SKU 模板管理列入扩展。

## 2. 传感器与坐标系

### 2.1 相机与模型

| 模块 | 配置 | 用途 |
|-|-|-|
| 头部相机 | 双目鱼眼 1920×1536；cam0/cam1 | 场景检测与双目深度 |
| 头部模型 | yolopose_3cls_20261105163435_041ee5 | 三类检测 + 四关键点 |
| 腕部相机 | 左腕 Gemini305 1280×800；彩 cam13 / 深 cam12 | 近距离定位 |
| 腕部模型 | yolo_pose_26x_wrist（imgsz=960）或配置中的小板腕权重 | 小板检测与关键点 |
| 轮廓模板 | d435_pcb.npz | 离线板形；文件名不代表当前腕相机型号 |
| 头部深度 | Fast-FoundationStereo（FFS） | 深度质量检查 / 可选深度定位 |
| 腕深度单位 | uint16 mm × 0.001 → m | 反投影 |
| 运动后端 | RIM `move_to_pose` | 接收基座系 TCP 目标 |

检测要求四个关键点全部通过阈值；缺角与严重截断不在保证范围。

### 2.2 坐标系与标定

计算用米、弧度；展示可用毫米、角度。RIM 使用 `base_link` 与 `arm_l_linkTCP`（配置注明 linkTCP 对应夹爪尖端）。

- 头部：固定外参 `T_base_cam`。
- 腕部：`T_base_cam = T_base_tool × T_tool_cam`。
- 姿态：`Rz × Ry × Rx`。
- P0～P3 保持模型语义顺序，不按图像左右重排。

头部图像先鱼眼校正与双目校正；腕部按八参数畸变去畸变，彩色与深度同映射。须验证：头部外参光学坐标与校正图像射线一致；腕部彩色—深度对齐。

### 2.3 头腕协同

头部负责全局找料与初始接近；腕部负责局部精定位。两级结果在**基座坐标**关联，不直接比较像素。最终精度同时受粗定位、手眼标定、腕部视野与采集时机器人状态影响。

| 阶段 | 空间约束 | 一致性要求 | 输出 |
|-|-|-|-|
| 头部全局 | 已知水平板面 | 校正内参与外参光学坐标一致 | 实例选择、初始接近 |
| 腕部局部 | 目标近距离可见 | 彩深对应、位姿与采集时刻对应 | 板心与方向 |
| 头腕关联 | 同一基座系 | 类别、距离、任务目标一致 | 确认精定位对象 |

## 3. 总体流程与目标选择

### 3.1 处理流程

```text
头部左右图像
  → 校正图 YOLO-Pose 多帧检测
  → 选检出实例最多的代表帧
  → FFS 深度与质量检查
  → 校正图再检测
  → 四角转基座、分配 ID、选择小板目标
  → 腕相机接近 → 停稳 → 腕部检测与轮廓匹配
  → 深度反投影 → 头腕关联 → 多帧稳健选帧
  → 板心 XY 与方向 → 单臂抓取 / 供姿目标
```

### 3.2 实例编号与选择

头部实例按距基座原点 XY 距离排序编号 1、2、3…（本轮场景编号，非跨轮物料 ID）。

小板在小板候选内按距离顺序选目标；配置 `target_board_id` 表示类别内第 N 个候选。正式集成须：**硬过滤可抓类别**（禁止空槽进入抓取），并由上层管理目标替换。

## 4. 头部检测与粗定位

### 4.1 任务与选型

完成识别、四角提取与初始基座定位，输出 `ObjectPose` 供腕部观测接近。

固定板面法利用已知工位高度，将二维角点转为基座平面位置，避免默认链路逐角依赖局部深度。适用：板面高度已知且近似水平。

| 路径 | 方法 | 适用 | 限制 |
|-|-|-|-|
| 板面约束（默认） | 像素射线 ∩ 已知基座平面 | 已知水平工位 | 高度误差传入 XY |
| 深度定位（可选） | FFS 深度反投影 | 有有效深度 | 依赖深度与校正一致性 |

FFS 在默认板面路径中仍做质量检查。

### 4.2 检测与深度门控

默认 5 帧、帧间隔 0.03 s；选检出最多的代表帧（非多帧位姿中值融合）。FFS 不通过则报错；通过后在对应校正图再检测。

### 4.3 板面位姿解算

当前板面高度配置非空时，像素射线与水平面 Z=`head_tray_z_m` 求交：

```text
d = K⁻¹ p
v = R d
λ = (Z_plane − t_z) / v_z
P = t + λ v
```

P0～P3 转基座后取均值作板中心；方向由板边向量经夹爪角转换函数得到。射线平行板面或交点无效则拒绝。

板面高度变更、明显倾斜或堆叠时，须更新高度或切换并验证其他定位路径。

## 5. 小板精定位与抓取点生成

### 5.1 任务与方法

目标：夹爪对准可抓板心并给出正确平面方向。输入为腕 RGB-D、四关键点、轮廓模板、手眼外参与当前工具位姿；输出板心基座位置、抓取方向与匹配诊断。执行用精定位 XY/方向；抓取 Z 按示教高度。

| 方法 | 中心 | 方向 | 用途 |
|-|-|-|-|
| 关键点 | 四角几何 | 有序板边向量 | 初值与纯关键点路径 |
| 局部轮廓匹配 | 模板—边缘距离最小化 | 关键点限定搜索方向 | 修正板心；输出分数/尺度 |
| 深度反投影 | 像素中心 + 有效深度 | 结合外参 | 转到基座坐标 |

### 5.2 腕部观测位

依据粗定位板心与手眼关系，构造相机光心约在板面上方 **0.30 m**、光轴朝下的观测位。到位后静止检测（如稳定 1 s、位置 1.5 mm、旋转 0.015 rad 等）——这是运动静止判据，不是视觉精度。

### 5.3 外轮廓 Chamfer 匹配

腕部 YOLO-Pose 给出 box 与关键点；在 ROI 内提边，与离线模板 Chamfer 匹配：

```text
E(t, θ, s) = meanᵢ D(s · R(θ) · qᵢ + t)
```

分数越低贴合越好，不是概率或毫米误差。

| 参数 | 当前逻辑 |
|-|-|
| 初始角 | 关键点向量；最终抓取 rz 以轮廓角为准（实现以代码为准） |
| 角度搜索 | 初值 ±30°；不做 180° 模板翻转搜索 |
| 步长 | 粗 3° / 细 0.5°；中心半径约 12 px |
| 尺度 | 由检测框估计，初值附近 ±20%（**相对带**，非绝对外尺寸锁） |
| 分数参考 | Chamfer 均值，阈值配置 5.2（当前偏诊断；抓取硬门控需验证后定） |

### 5.4 位姿与深度

匹配中心 (u,v) 用于板心；深度按邻域 → 局部中值 → 框中值 → 悬停高度回退取值。全部不可用则失败。固定高度回退为近似，评测须分组。

```text
P_cam = [(u−cx)Z/fx, (v−cy)Z/fy, Z]
P_base = T_base_tool × T_tool_cam × P_cam
```

### 5.5 实例关联与多帧

腕部结果与头部实例按基座 XY 贪心匹配，最大距离约 0.12 m。正式集成须加同类别与任务目标约束。多帧 MAD + 中值筛选后取代表帧；启用轮廓匹配时可用代表帧匹配覆盖中值。角度可按头部方向消 180° 歧义。

### 5.6 抓取 / 供姿目标

- 精定位板心 XY 对准末端；执行姿态 `rx=−90°, ry=0°, rz` 按工具角偏置生成。
- 示教 TCP 高度与抬高量以配置数值为准（如 grasp_z + lift）。
- 视觉 Z 与执行 Z 分开保存；返回成功 ≠ 已稳定提起。

## 6. 输出与异常

### 6.1 主要输出

| 输出 | 内容 |
|-|-|
| PcbDetection | box、四关键点、类别、置信度 |
| ObjectPose | xyz、rz、corners_base、board_id、cls_id… |
| WristMatchInfo | 像素中心、模板角、尺度、分数、ok、深度 |
| 每轮 result | coarse/fine、目标 ID、阶段、图像与消息 |

注明坐标语义；`rz` 为抓手方向映射量，勿与纯板边 yaw 混用。

### 6.2 异常处理

| 异常 | 基线 | 集成要求 |
|-|-|-|
| 关键点不齐 | 过滤目标 | 不继续解算 |
| FFS 失败 | 报错 | 记录阶段，上层决定重采 |
| 匹配分数差 | ok=false 未必硬停 | 显式质量状态与抓取阈值 |
| 腕深不可用 | 逐级回退 | 记录深度来源，分组统计 |
| 目标未匹配 | 可回退其他实例 | 同时传请求 ID / 实际 ID |
| 运动失败 | 留存阶段消息 | 与感知失败分开统计 |

## 7. 验证与验收

### 7.1 已有真机证据（摘要）

正式编号实验见交付测试报告（001～011）：闭环抓取成功率 3/4；定位供姿轮给出粗→精 Δxy / Δrz 统计。须区分感知失败与运动到位失败；程序 ok ≠ 提起成功。

### 7.2 验收方法

1. 感知：分类、漏检、误检、关键点可用率。  
2. 定位：独立真值测 XY / 方向；报告 n、均值、P95、最大；深度回退分组。  
3. 关联：相邻板、候选变化、回退时 ID 正确性。  
4. 执行：接近、对准、夹持、提起分别统计；完整成功需持物判据。  
5. 节拍：取流 / 检测 / FFS / 匹配 / 运动分项计时。
