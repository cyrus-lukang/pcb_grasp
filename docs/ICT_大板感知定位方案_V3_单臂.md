# ICT 大板感知定位方案 · V3

## 方案摘要

本方案为 **大板单臂支路**（相对 V2 双臂头腕协同的新增路径）。不使用头部相机，由 **右臂腕部相机 cam3** 完成粗定位与精定位，输出单一末端停位，供右臂执行。

核心链路：右腕在当前位姿（或配置的粗定位法兰）采集彩色与深度 → **四角模型**以真实深度抬出基座系 P2、P3 → 右臂末端垂直向下，依次到达粗 P2、粗 P3 上方 **15 cm** 拍腕 → **单角模型**以固定相机深度 15 cm 刷新精 P2、精 P3 → 停在 `mid(P2,P3)` 经 Y 向偏移后的 tip，高度为板面上方 **10 cm**（相对精拍高度下降 5 cm）。

适用条件：板面近似水平、P2/P3 在右腕视野可达、右腕手眼与 cam3 深度可用。本路径不产出左右双 tip，也不进入 V2 的双臂接近 / 内收流程。

## 1. 单臂大板识别思路

### 1.1 与双臂路径的分工

| 项目 | V2 双臂 | V3 单臂（本方案） |
|-|-|-|
| 粗定位传感器 | 头部双目 | 右腕 cam3（彩色 + 深度） |
| 粗定位模型 | 头三类别 YOLO-Pose 四角 | `pcb-large-1` · `0ca8f6`（4 角） |
| 精定位执行 | 左腕看 P3、右腕看 P2 | **仅右臂**依次看 P2、再看 P3 |
| 精定位模型 | 大板角点模型（历史权重见 V2） | `corner-1` · `90459c`（单角） |
| 精拍姿态 | 相机朝下悬停 | **夹爪 tip 垂直向下**（end-down） |
| 深度策略 | 粗/精多与固定板面求交 | 粗用 **真实腕深**；精用 **固定 cam 深 0.15 m** |
| 输出 | 左右接近 tip + 内收 | 单一停 tip（mid + Y 偏置） |

平台入口：`force_class=large_single`（UI「大板单臂」）。运控主臂为右臂（arm B），手眼使用 `T_tool_cam_right`。

### 1.2 四角语义与参考边

P0～P3 语义与训练标注一致，不按图像方位重排。粗定位保留完整四角；停位与朝向只使用 **P2、P3**。参考中点：

```Plain Text
M = (P2 + P3) / 2
```

M 是夹取几何基准，不是四角几何中心。工具中间线目标平行于 P2→P3。

## 2. 整体流程

图 1｜单臂大板腕粗 → 精 P2/P3 → 停位

```Plain Text
01 粗定位取流（右腕 cam3 / 深度 cam2）
   → 四角模型检出 + 角点真实深度 → 基座系粗 P0～P3，取 P2、P3
02 精拍到位 P2：tip = (P2.x, P2.y, P2.z + 0.15)，末端垂直向下
   → 单角模型 + 固定 cam 深 0.15 m → 精 P2
03 精拍到位 P3：同上高度与姿态 → 精 P3
04 合并角点，更新 M 与朝向
05 停 tip = (M_x, M_y − 0.13, Z_board + 0.10)，末端仍垂直向下
```

粗定位拍照位默认使用当前右臂 TCP；若配置了 `coarse_flange_pose`，则先运动到该法兰再拍粗图。`plan_only` 不动臂，仅在当前位姿尝试检测；精拍未成功时保留粗角点。

## 3. 腕部粗定位（真实深度）

### 3.1 模型与取流

粗定位权重：`yolopose_pcb-large-1_…_0ca8f6/best.pt`。输入尺寸 480，要求检出 **4 个角点**。彩色 portal **cam3**，深度 **cam2**（映射到彩色坐标系后采样）。

每帧同时读取右臂法兰位姿，计算：

```Plain Text
T_base_cam = T_base_tool × T_tool_cam_right
```

### 3.2 多帧筛选

与现有感知配置一致：多帧采集（默认 10 帧）、帧间隔与 MAD 筛选后，取最接近均值的一帧代表结果。四角取自同一代表帧，保持同帧几何，不做逐角跨帧平均。

任一角点处深度无效（缺失或过近）时，该帧不作为粗定位样本。粗定位失败则本轮结束，不进入精拍。

### 3.3 真实深度抬点

对每个角点像素 `(u,v)` 在深度图采样得到相机系深度 `z_cam`，再经 `T_base_cam` 变换到基座：

```Plain Text
P_cam = π⁻¹(u, v, z_cam; K_wrist)
P_base = T_base_cam · P_cam
```

粗定位的 **XY 与角点 Z 均来自真实深度**，不与头部固定板面求交混用。板面参考高度 `Z_board`：若已标定 `large_board.grasp_z_m` 则用之；否则取粗四角 Z 的均值。后续精拍悬停高度按「角点 Z + 15 cm」理解；停位高度按「`Z_board` + 10 cm」理解。

## 4. 右腕角点精定位

### 4.1 观测高度与姿态

精拍到位由粗角点驱动。对目标角点 `C`（先 P2 后 P3）：

```Plain Text
tip = (C_x, C_y, C_z + h_hover)
h_hover = 0.15 m   # single_arm.fine_hover_height_m
```

姿态为右臂 **end-down**：`rx=+90°`、`ry=0°`、`rz` 由 P2→P3 映射（相对左臂约定再绕竖轴 +180°）。`tool_y_m`、`tool_z_m` 为 0 时，规划点即夹爪 tip TCP，不再二次补偿工具长度。

该到位高度即「精定位开始识别的高度」，也是粗定位给出的到达高度：末端距角点约 15 cm。

### 4.2 依次更新 P2、P3

右臂先到粗 P2 上方完成检测，再移至粗 P3 上方。两侧角点非同时刻测得，板件在流程中须保持静止。单侧失败时该侧回退粗角点并记录来源；双侧失败则停位仍可基于粗 `M` 规划，但不作为精定位验收依据。

精定位模型：`yolopose_corner-1_…_90459c/best.pt`（单角，imgsz=480）。每帧可能检出多个角点候选，取距当前粗目标 XY 最近、且在匹配阈值内（默认 0.15 m 量级，实现上允许约 2× 容差）的一点。

### 4.3 固定相机深度反投影

精拍时相机距板较近，腕部深度常不可用。本路径 **不读取精拍帧深度**，统一使用固定相机深度：

```Plain Text
z_fixed = 0.15 m   # single_arm.fine_fixed_depth_m
P_cam = π⁻¹(u, v, z_fixed; K_wrist)
P_base = T_base_cam · P_cam
```

精角点写入基座 XY 后，Z 记为 `Z_board`（与停位板面高度同源）。不能把「固定 15 cm」理解成 tip 再抬高 15 cm；15 cm 同时约束了 tip 悬停与相机反投影假设，二者配置同值，几何上仍取决于手眼与 tip 定义。

### 4.4 合并与参考中点

```Plain Text
成功则：P2 ← 精 P2，P3 ← 精 P3
M = (P2 + P3) / 2
方向 ← P2 → P3
```

分析修正量时应比较同一角点的粗/精坐标，或比较粗、精各自算出的 `M`，避免与四角均值中心混淆。

## 5. 停位生成

### 5.1 停 tip 公式

```Plain Text
M = (P2 + P3) / 2
tip_stop = (M_x, M_y + Δy, Z_board + h_stop)
Δy = −0.13 m    # single_arm.stop_dy_m
h_stop = 0.10 m # single_arm.stop_z_above_board_m
```

若显式配置 `stop_z_m`，则直接覆盖 tip 的 Z，不再使用 `Z_board + h_stop`。

图 2｜基座 XY：P2、P3、M 与停 tip（示意）

```Plain Text
        +Y
         ↑
    P3 · · · · · P2     （示意，实际方位随板姿）
           M
           ↓ Δy = −0.13 m
        tip_stop
         → +X
```

### 5.2 姿态

停位姿态与精拍相同：右臂 tip 垂直向下，中间线平行 P2→P3（含 `orient_rz_offset_deg`，当前默认 0°）。

### 5.3 高度关系

| 阶段 | tip Z（相对板面） | 说明 |
|-|-|-|
| 精拍识别 | `Z_corner + 0.15` | 粗定位到达 / 精定位开始 |
| 停位结束 | `Z_board + 0.10` | 相对精拍名义高度下降 **5 cm** |

实机联调时以 tip TCP 读数核对：从精拍位到停位，末端高度变化应接近 5 cm；若手眼或 tip 定义不一致，须先校核再改偏移参数。

## 6. 输出、异常与入口

| 输出 | 内容 |
|-|-|
| 粗定位 | 四角基座坐标、板 ID、代表帧可视化 |
| 精定位 | 精 P2/P3（或回退粗）、`M`、朝向 |
| 停位 | tip / 法兰六维、CLI 复现命令（`--arm right`） |

| 异常 | 处理 |
|-|-|
| 粗检无 4 角或深度缺失 | 本轮失败 |
| 单侧精检失败 | 该侧用粗角点，结果中标明来源 |
| 右腕手眼缺失 | 警告后回退左腕手眼（仅保证可运行，不保证几何正确） |
| `plan_only` | 不动臂；能检则检，不能则保留粗结果 |

工程入口：`pcb_grasp` Web UI → 流程选「大板单臂」；配置节 `large_board.single_arm`。实现模块：`run_large_single_arm`（pipeline）、右腕手眼 `calib.T_tool_cam_right`。

本页只描述 **新增单臂大板** 感知与停位；双臂头腕协同与内收见 [ICT 大板感知定位方案 · V2](https://airimbot.feishu.cn/wiki/BWrpw8ohTi7zGAk4pYFc2lWhnUc)。
