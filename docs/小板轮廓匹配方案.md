# PCB 小板 · 腕部外轮廓匹配方案

> 用途：小板抓取的**腕部精定位**（`shape_match` / `pose_outer_refine`）  
> 代码：`pcb_grasp/shape_refine.py` · `TCT/pose_outer_refine.py` · `TCT/shape_matcher.py`  
> 配置：`config/grasp_config.yaml` → `shape_match` / `models.shape_model`

---

## 1. 一句话

**不是「box → 分割网出 mask → mask 边缘匹配」。**  
腕部 YOLO-Pose 出框和关键点定初始朝向后，在 ROI 内用**经典视觉提边**，与离线板形模板做 **Chamfer 匹配**，微调中心 `(u,v)`、朝向角、尺度，再结合深度投影到基座 `xyz/rz`。

---

## 2. 在整条抓取链路中的位置

```
头 YOLO-Pose（粗） → 基座悬停 → 腕 D405
                         ↓
              腕 YOLO-Pose（框 + 关键点）
                         ↓
              外轮廓 Chamfer 匹配（本方案）
                         ↓
              像素位姿 + 深度 → 基座 ObjectPose
                         ↓
              降 Z → 收夹爪
```

| 阶段 | 模型/方法 | 输出 |
|------|-----------|------|
| 头粗定 | YOLO-Pose 3cls=`pcb_small(0)` | 悬停目标、board ID |
| 腕检测 | YOLO26x-Pose `wrist_pose_960` | box、关键点 |
| **腕精定** | **外轮廓模板匹配** | 精 `(u,v,θ,scale)` → `xyz/rz` |
| 夹取 | 运动 + 夹爪 | 单臂 A 收夹 |

开关：`shape_match.enable` / `fine_use_shape_match`（默认 `true`）。关闭则退回纯关键点定位。

---

## 3. 输入 / 输出

### 输入

| 项 | 来源 |
|----|------|
| 腕 RGB | D405 color |
| 腕深度 | D405 depth（匹配中心取深，失败用 box ROI 中值） |
| 检测 | 腕 YOLO-Pose → `PcbDetection`（corners≥2、可选 box） |
| 模板 | `TCT/shape_match/models/d435_pcb.npz`（`ShapeModel`） |
| 手眼 / EE | `T_tool_cam`、当前法兰 `ee_xyz_rpy`、内参 `K` |

### 输出

| 项 | 含义 |
|----|------|
| `ObjectPose` | 基座 `x,y,z,rz`（rz 走 `baseYAngleToGripperRz`） |
| `WristMatchInfo` | 像素 `x,y`、`angle_deg`、`scale`、`score`、`ok`、关键点角、深度、可视化 |

## 4. 算法流程

### 4.1 关键点定初始角

- 取关键点 **P1 → P0** 向量  
- `angle_kpt = atan2(dy, dx)`（图像系，逆时针为正）  
- `angle0 = normalize(angle_kpt + angle_offset_deg)`  
- **不做 180° 翻转搜索**；朝向由关键点锁定，匹配只在 `angle0 ± angle_range` 内微调

### 4.2 ROI

- 用检测 box（无 box 则用关键点包围盒）外扩 `roi_margin`（默认 0.25）  
- 后续提边与匹配都在 ROI 裁剪图上做

### 4.3 场景边提取（无分割网络）

`refine_outer_near_pose` 按优先级：

1. **`extract_coarse_outer_edges`**：模糊 → Canny → 保留足够长的轮廓线  
2. 失败 → **`extract_outer_ring_edges`**（配置 `edge_mode: outer-ring`）  
   - HSV 绿/阈值或 Otsu 得到**伪前景**（经典阈值，非 Seg/SAM）  
   - 最大外轮廓填成伪 mask  
   - 膨胀−腐蚀得**外环**，与 Canny 求交，滤短连通域  
3. 再失败 → 纯 Canny / silhouette

因此：可能出现「伪 mask」，但它是**阈值形态学**产物，**不是** YOLO-Seg / SAM 对 box 的实例分割。

### 4.4 模板与 Chamfer 搜索

- 模板点集：`ShapeModel.outer()`（离线从板形掩膜/抠图建的外形点，原点≈外形质心）  
- 尺度初值由 box 宽高相对模板尺寸估计，并在 `±scale_rel` 内抽样  
- 在 `angle0 ± angle_half_range` 内：  
  - **粗搜**：较大角步长 / 较大平移步长 / 少点采样  
  - **细搜**：角步 0.5°、平移步 1 px 等  
- 评分：模板点投到场景距离变换图上的 **Chamfer 距离**（越小越好）  
- `score < score_thresh` 且搜索有效 → `ok=true`

### 4.5 像素 → 基座位姿

1. 在匹配中心 `(u,v)` 取深度 `depth_m`  
2. 沿匹配角在图像上取一小段 tip 点，反投影到相机系再变换到基座  
3. `rz = baseYAngleToGripperRz(p0, p1)`（与整机夹爪约定一致）  
4. `z` 用当前深度投影；抓取阶段再降到示教 `grasp_z_m`

## 5. 与常见误解对照

| 误解 | 实际 |
|------|------|
| box 后跑分割网出 mask，再匹配 mask 边缘 | **无**分割网；ROI 内 Canny / 阈值外环提边 |
| 轮廓匹配单独识别物体 | 识别靠 **YOLO-Pose**；匹配只做平面位姿精修 |
| 模板在线从当前帧分割生成 | 模板是离线 `d435_pcb.npz`；线上只读不训 |
| 搜索全角度含 180° | 角由 **P1→P0** 锁定，仅 ±range 微调 |

## 6. 配置项

`config/grasp_config.yaml`：

```yaml
models:
  wrist_pose_weights: models/wrist/yolo_pose_26x_wrist_960_best.pt
  shape_model: TCT/shape_match/models/d435_pcb.npz

shape_match:
  enable: true
  angle_offset_deg: 0.0      # 关键点角系统偏差补偿
  angle_range_deg: 30.0      # 半幅搜索范围（±）
  edge_mode: outer-ring      # outer-ring | canny | silhouette | auto
  score_thresh: 5.2          # Chamfer 通过阈（越小越严）
```

常用默认（代码内，可按需暴露）：`roi_margin=0.25`，`ring_width=18`，Canny `40/120`，粗角步 3°、细角步 0.5°。

## 7. 模板制作（离线）

位置：`TCT/shape_match/`

1. 准备小板抠图或二值 mask（黑底 / alpha / 二值图）  
2. `build`：从最大外轮廓采样点 → 存 `*.npz`（质心为原点）  
3. 当前生产模板：`models/d435_pcb.npz`（腕相机视角标定）  
4. 板型变更、镜头/工作距大变时需重建模板并复测 `score_thresh`

## 9. 失败与调参建议

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| `score` 很大 / match fail | 边提不稳、遮挡、反光 | 查 ROI 可视化；调 Canny / `ring_width`；改善光照 |
| 角偏 180° | 关键点 0/1 标反或模型角点乱 | 查腕 Pose 关键点顺序；调 `angle_offset_deg` |
| XY 偏但角对 | 深度噪点 / tip 长度 | 查深度中值；核对手眼 |
| 经常 `ok=false` | 阈过严或模板不符 | 略放宽 `score_thresh`；重建模板 |
| 匹配贴到邻板/托盘边 | ROI 过大或外环吃到背景 | 减小 `roi_margin`；加强外环/长度过滤 |

可视化：`WristMatchInfo.vis`（关键点角 + 模板投影叠加场景边）。

---

## 10. 边界与适用范围

- **仅小板腕精定**；大板走头 Pose 角点 + tip 几何，不用本匹配  
- **空槽 nopcb** 可被腕 Pose 检出，但不作为抓取目标  
- 假设板近似平面、外形与模板一致；严重破损/异形板需换模板或关匹配回退关键点  
- 与托盘方案的「CAD 轮廓精修」无关：托盘是 YOLO-Seg + CAD SE(3)；小板是 Pose + 2D Chamfer

---

## 11. 小结

小板轮廓匹配 = **腕 YOLO-Pose（身份与初始角）+ ROI 经典提边 + 离线外形 Chamfer 精修 + 深度投影**。  
识别靠 Pose，精修靠边，**没有**「对 box 再跑分割模型出 mask」这一步。
