# 2. 实验背景与目标

## 2.1 背景

大板走「头部四角几何 → 双臂夹持点」路径（无腕部精定位）。调试中出现：两臂相对板中心/边缘不均匀、板倾斜后右臂朝向仍像正放、以及 tip_span=43 cm 时右臂易蹭边等问题。

## 2.2 待验证项

| 验证项 | 目标/假设 | 评价指标 | 通过条件 |
|-|-|-|-|
| 头定位选板 | 稳定检出大板四角 | conf、角点可见 | 检出 cls=2 且四角可用 |
| 左 tip 几何 | 左 tip = mid(P0,P3) | 相对视觉左边距离 | 贴左边、观感可用 |
| 双臂间距 | 右 tip = 左 + tip_span | ‖tipR−tipL‖ | 配置 470 mm；右臂不撞边 |
| 接近外开 | 相对 tip 各外开 open | 接近间距 | tip_span + 2×open |
| 姿态平行 | 板倾斜时两臂平行 | 观感 / toolZ | 左右平行、贴板方向正确 |
| 接近到位 | 双臂到接近位 | 现场判定 | 到位且可内收 |
| 本阶段任务 | 接近 + 内收可用 | 成功/失败 | 不以自动合拢为必须 |

尚未设定：合拢贴边力、抬板、搬运成功率阈值。

# 4. 实验方法与步骤

**已执行流程：**

1. 连接相机 + 机械臂；大板放入头视野（含斜放）。
2. 全流程：头多帧检测 → 四角 ∩ 固定 Z=grasp_z → 生成左右 tip/接近位。
3. 双臂运动到接近位（同高；外开 open_margin）。
4. 网页「内收 5mm」步进；点「结束」退出（无自动合拢）。
5. （未执行）力控合拢贴边、抬板、放料。

**成功判据（本阶段）：** 定位与接近位姿正确，双臂到位后可用、未撞板/未出现不可接受偏姿。  
**失败判据：** 现场判定接近/姿态不可用或未达到可内收状态。

# 7. 实验结论与局限

**已验证：**

- 大板头定位 + 双臂接近/内收在本机配置下 **成功率 80%（4/5）**；
- tip_span=0.47 m、open=0.05 m、左钉左边 + 右=左+span、rz+180° 平行约定已用于本轮实验。

**未通过 / 未测：**

- 005 失败轮原因待补写具体现象；
- 合拢贴边、抬板、搬运未验收；
- 角点/跨度相对真值的定量误差表未做。

**局限：** 001～004 缺图像，成功依赖现场判定；单日同机，不推广为产线长期可靠性。
