# PCB 大板视觉定位与双臂夹取方案

## 1. 方案概述

### 1.1 目标

面向 ICT 产线 PCB 大板双臂夹持场景，建立「头部全局粗定位 + 腕部角点精定位」的感知链路，输出左右臂夹持点与姿态，供运动模块执行接近与夹持。

核心流程：

**头部四角粗定位 → 左右腕精定位（左看 P3、右看 P2）→ 生成双侧夹持点 → 双臂接近并夹持**

适用条件：板面高度已知、板近似水平、四角可见。大倾角与堆叠的完整 6D 估计不在本方案范围。

### 1.2 任务定义

| 项目 | 说明 |
|-|-|
| 检测对象 | PCB 大板（头部模型类别 pcb_large） |
| 粗定位 | 头部双目鱼眼检测四角关键点，与已知板面高度求交，得到基座系四角坐标 |
| 精定位 | 左腕至粗定位 P3 上方、右腕至粗定位 P2 上方，腕部角点模型再次检测，刷新精 P2/P3 |
| 夹持点 | 以精定位 mid(P2,P3) 为基准，按标定偏移生成左右 tip；夹爪朝向与 P2→P3 平行 |
| 高度 | 独立标定的大板夹持高度 `grasp_z`；腕部精定位悬停高度默认板面上方约 10 cm |
| 输出 | 左右臂基座系夹持 / 接近目标（位置 + 姿态） |

### 1.3 精度与验收口径

| 指标 | 目标 | 验证方式 |
|-|-|-|
| 类型识别 | >99.9% | 独立测试集 |
| 角点粗定位 | <5 mm | 基座角点相对真值 |
| 角点精定位 | 相对粗定位收敛；统计精−粗平面偏差 | 同板 ID 下腕精前后对比 |
| 夹持跨度 / 位置 | <1 cm | 视觉几何相对实物测量 |
| 姿态方向 | 满足项目统一公差 | 执行 rz 相对 P2→P3 |
| 夹持成功率 | 按项目交付指标 | 接近—夹持—持物分段统计 |

## 2. 系统组成

### 2.1 传感器与模型

| 模块 | 配置 | 作用 |
|-|-|-|
| 头部相机 | 双目鱼眼 | 全局检测与粗定位 |
| 头部检测模型 | YOLO-Pose 多类（含大板） | 检出大板并输出四角关键点 |
| 头部深度 | 双目立体深度 | 图像质量检查；大板角点高度采用标定板面，不以角点深度为主 |
| 左腕相机 | 眼在手上 | 精定位观测 P3 |
| 右腕相机 | 眼在手上 | 精定位观测 P2 |
| 腕部检测模型 | YOLO-Pose · corner（大板专用） | 近距离角点精定位 |
| 手眼标定 | 头部外参；左右腕工具—相机外参 | 像素坐标与基座坐标互转 |
| 运动执行 | 双臂控制系统 | 按感知输出到达夹持目标 |

### 2.2 坐标约定

- 统一工作坐标系：机器人基座。
- 左右末端控制点：夹爪 tip（TCP）。
- 角点编号 P0～P3 与检测模型语义一致；精定位重点使用 P2、P3。
- 交付与联调前须确认：感知输出的控制点语义与运动控制点一致，工具偏置已校核。

## 3. 总体流程

```text
头部采集左右图像
  → 校正后多帧检测，稳定选取代表结果
  → 四角与标定板面高度求交，得到粗定位四角与板 ID
  → 左臂携带腕相机至粗 P3 上方悬停并检测 → 得到精 P3 → 返回
  → 右臂携带腕相机至粗 P2 上方悬停并检测 → 得到精 P2 → 返回
  → 由精 P2/P3 计算 mid 与左右夹持点、姿态
  → 双臂运动至夹持目标并完成夹持
```

存在多板时优先选择大板目标；板 ID 用于粗—精匹配，保证腕部观测对应同一块板。

## 4. 头部粗定位

1. 头部双目采集并校正，YOLO-Pose 检测大板四角。  
2. 多帧检测后做稳健筛选，降低单帧抖动。  
3. 四角像素射线与已知板面高度求交，得到基座系 P0～P3。  
4. 为场景中各板分配 ID，选定本轮抓取目标。

四角不全时本轮定位失败，不进入「缺角凑合」路径。

## 5. 腕部精定位

粗定位给出的 P2/P3 受头部视距与畸变影响，近距离夹持前需腕部补精。

| 步骤 | 动作 | 结果 |
|-|-|-|
| 1 | 左臂将腕相机移至粗定位 P3 上方（默认约 10 cm），光轴朝下检测 | 精 P3 |
| 2 | 右臂将腕相机移至粗定位 P2 上方同高检测 | 精 P2 |
| 3 | 按板 ID（必要时辅以角点距离）匹配粗—精结果并合成 | 精定位板姿（中心≈ mid(P2,P3)，朝向∥P2→P3） |

说明：

- 腕部使用大板专用角点模型，与其它板型权重分离。  
- 任一侧精定位失败时，该侧回退为头部粗角点，并在结果中记录，避免静默漂移。  
- 精定位完成后两侧回到粗定位后的准备位姿，再进入夹持点规划与运动。

## 6. 夹持点生成

以精定位后的 P2、P3 为输入：

```text
mid = (P2 + P3) / 2
左 tip = mid + (dx, +dy)
右 tip = mid + (dx, −dy)
左臂朝向：夹爪中线 ∥ P2→P3
右臂朝向：相对左臂绕竖直轴相差 180°
高度 Z = 标定 grasp_z
```

其中 `dx`、`dy` 为标定偏移（基座坐标：左臂侧为 +Y、右臂侧为 −Y）。夹持点与接近点均在基座系计算，不以像素中点代替。

定位结果可将夹持点反投影至头部图像，便于联调对照。

## 7. 输出与异常处理

| 输出 | 内容 |
|-|-|
| 粗定位结果 | 四角基座坐标、板类别、板 ID |
| 精定位结果 | 精 P2/P3、mid、朝向 |
| 夹持规划 | 左右 tip / 接近目标、偏移参数、高度 |

| 异常 | 处理原则 |
|-|-|
| 头部四角不全 | 本轮失败，不生成夹持点 |
| 腕部未检出或匹配失败 | 该侧回退粗角点并告警；双侧均失败则不进入实夹验收 |
| 高度 / 偏移未标定 | 标记待标定，实夹前必须完成 |
| 运动未到位 | 与感知失败分开统计 |

## 8. 验证与交付要求

1. **感知**：大板检出率、四角完整率；左右腕精定位检出率与板 ID 匹配率。  
2. **几何**：精相对粗的平面偏差；左右 tip 相对真值；朝向相对 P2→P3。  
3. **执行**：接近到位、夹持、持物分段统计。  
4. **节拍**：头部检测、左右腕精定位、双臂运动分项计时。

交付前须完成：TCP 语义与工具偏置校核、夹持高度与平面偏移标定、大板腕部模型与左右手眼可用、实机基线测评。

## 附录

本方案仅覆盖 PCB 大板「头部粗定位 + 腕部精定位 + 双臂夹持点生成」。实现与配置见工程模块 `large_board`、双臂大板流程及左右腕手眼标定结果。
