# ICT 大板感知定位与双臂夹持方案

> 小板单臂抓取方案见独立文档。本文仅描述 PCB 大板的头部几何定位与双臂夹持点生成。

## 1. 方案概述

### 1.1 目标

面向 ICT 产线 PCB 大板双臂夹持，在头部全局检测基础上，由四角基座几何生成双侧夹持点与接近/合拢目标。感知输入为头部图像、深度、标定与机器人位姿；输出运动模块可用的左右臂基座坐标目标。

大板流程为：**头部四角定位 → 基座平面几何 → 双臂夹持点与外开接近 →（确认后）合拢**。

本版本**不接入腕部精定位**。适用：已知高度、近似水平、四角可见的大板。任意倾斜与堆叠的完整 6D 估计不在范围。

### 1.2 感知任务定义

| 项目 | 内容 |
|-|-|
| 头部检测类别 | pcb_large（class 2） |
| 头部定位 | 四角射线与已知板面求交，保留四角基座坐标 |
| 接近方式 | 按两侧夹持点生成外开接近位 |
| 近距离精定位 | 当前未接入 |
| 位置输出 | 左侧边中点及沿内法向构造的右侧夹持点 |
| 方向依据 | P0→P3 边方向转换后 +90°，两臂同 rz |
| 高度来源 | 独立大板标定高度优先；否则角点 / 板面高度 |
| 执行动作 | 两臂自板外侧沿相反方向接近；合拢为双臂位移（非收夹爪） |

### 1.3 与小板的分工

| 项目 | 大板（本文） | 小板（另文） |
|-|-|-|
| 局部定位 | 头部四角几何 | 腕部 YOLO-Pose + 轮廓匹配 |
| 几何目标 | 双侧夹持点、内法向、跨度、平行姿态 | 单板心与抓取方向 |
| 执行高度 | 大板独立高度优先 | 示教 TCP + 抬高量 |
| 接触动作 | 双臂向夹持点移动 | 下降后收夹爪 |
| 核验重点 | 双侧点误差、跨度、TCP 偏置、协同与接触 | 中心/方向误差、深度回退 |

### 1.4 精度与验收口径

| 指标 | 项目目标 | 验证方式 |
|-|-|-|
| 类型识别 | >99.9% | 独立测试集 |
| 角点定位 | <5 mm | 基座角点 vs 真值 |
| 尺寸 / 跨度 | <1 cm | 视觉几何 vs 实物；与标定 tip_span 分开统计 |
| 方向 | 与项目统一阈值 | 板边方向与执行方向分组 |
| 完整夹持 | 含视觉节拍目标按项目表 | 接近、合拢、持物分别统计 |

## 2. 传感器与坐标系

### 2.1 配置

| 模块 | 配置 | 用途 |
|-|-|-|
| 头部相机 | 双目鱼眼 1920×1536 | 检测与深度 |
| 头部模型 | yolopose_3cls（含 pcb_large） | 四关键点 |
| 头部深度 | FFS | 质量检查 / 可选深度定位 |
| 运动 | RIM 双臂 | 左右 TCP 目标 |

当前默认**不使用**腕部相机做大板精定位。

### 2.2 坐标约定

基座 `base_link`；左右末端 `arm_l_linkTCP` / `arm_r_linkTCP`。头部外参 `T_base_cam`；姿态 `Rz×Ry×Rx`。P0～P3 保持模型语义顺序。

**重要：** 大板几何路径中仍可能经 `tip_to_flange` 叠加历史 tool 偏置；而 RIM 目标语义为 linkTCP。**实抓前必须完成目标坐标对象与工具偏置校核。**

## 3. 总体流程

```text
头部左右图像
  → 校正图 YOLO-Pose 多帧检测
  → 代表帧 + FFS 质量检查
  → 四角转基座，分配 ID，选择大板目标
  → 夹持边与内法向
  → 左右夹持点 → 外开接近点与合拢目标
  →（可选）UI 确认后合拢
```

目标选择：存在大板时优先大板。编号为本轮场景排序 ID。

## 4. 头部检测与粗定位

与小板共用头部检测与板面/深度定位路径（见小板方案第 4 章）。差异在于：大板保留完整四角基座坐标，进入夹持几何，而非腕部接近。

四角缺失则检测或几何失败；不进入「缺角凑合」路径。

## 5. 夹持点几何

### 5.1 输入

头部输出的四角基座坐标。无腕部二次定位。

### 5.2 几何定义

以 P0—P3 为左侧参考夹持边，P1—P2 为对边：

```text
L = (P0 + P3) / 2
R_vis = (P1 + P2) / 2
e = normalize_xy(P3 − P0)
n = perpendicular(e)，并使 n 指向 R_vis
R = L + span × n
```

中点在基座坐标计算，不能用像素中点代替。右侧点落在参考边内法线上；仅当几何满足条件时才与视觉对边中点重合。

- **span**：优先标定 `tip_span_m`；否则兼容半宽；再否则用视觉两边中点距。过小宽度需几何检查。  
- **Z**：优先独立 `grasp_z_m`；否则角点/板面高度。  
- **rz**：两臂相同，`rz = wrap(base_y_angle_to_gripper_rz(P0,P3) + 90°)`。  
- 左右沿 n 的**相反方向**外开接近。

### 5.3 接近点与标定状态

默认左右自夹持点向板外偏移约 50 mm；额外内收量可配置。若 `grasp_z_m`、`tip_span_m` 为空，则依赖视觉/板面估计并标记 `calib_pending=true`，实抓前应完成独立标定。

### 5.4 执行边界

- UI 可在接近后等待确认再合拢；非所有入口强制回调。  
- 合拢靠双臂移动，不通过收夹爪。  
- 当前 RIM 双臂实现多为**顺序**执行左右臂，非同步协同轨迹。  
- 配置中的力阈（如 5 N）若后端未实现力控，则退化为慢速位置合拢——验收时不得把配置参数当成已具备力控。

## 6. 输出与异常

| 输出 | 内容 |
|-|-|
| ObjectPose（头部） | 四角、中心、类别、board_id |
| LargeBoardPlan | 两侧 tip、外开/合拢目标、间距、方向、calib_pending |
| 每轮 result | plan 预览、阶段、图像与消息 |

| 异常 | 处理要求 |
|-|-|
| 四角不全 | 不继续几何 |
| 标定参数空 | 标记 pending；实抓前完成标定与 TCP 校核 |
| 运动/到位失败 | 与感知失败分开统计 |
| 未确认合拢 | 停在接近位，不得记作夹持成功 |

## 7. 验证与验收

### 7.1 现状

已有记录中，明确标为 large 的条目多为 plan-only 几何预览；**大板双臂实抓证据仍不足**。正式交付前须补：独立真值下的角点/跨度误差，以及接近—合拢—持物全流程。

### 7.2 验收方法

1. 感知：大板分类与四角可用率。  
2. 几何：左右夹持点误差、跨度、内法向；工具偏置与控制点语义核验。  
3. 执行：接近、合拢、持物分别统计；顺序/同步与力控状态如实记录。  
4. 节拍：检测、几何、双臂运动分项计时。

## 8. 集成清单

| 优先级 | 工作项 | 完成判据 |
|-|-|-|
| P0 | 统一大板 TCP 语义与工具偏置 | 与 RIM 控制点一致，独立测量核验 |
| P0 | 完成 grasp_z / tip_span 标定 | calib_pending=false 且复测稳定 |
| P1 | 双臂同步与接触判定 | 不再仅依赖顺序位置合拢（若项目要求力控） |
| P1 | 大板实抓基线测评 | 独立真值 + 持物判据 |
