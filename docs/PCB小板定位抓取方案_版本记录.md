## 2. 背景、目标与范围

### 要解决的问题

PCB 托盘内多块小板的单臂抓取：头相机粗定选板 → 腕相机精修板心与朝向 → 下降收夹。

### 前版局限（来自 11-09 文档及后续真机现象）

- 悬停按「工具朝下 + Y/Z 让位」描述，与腕相机实际观测姿态不一致；305 光轴相对工具侧偏，tip 竖直时腕图未必利于精定位。
- 示教高度仍写法兰 Z≈−227 mm；工程已改 tip=`linkTCP`，数值口径过时。
- 粗定位若按板边转 rz，易把目标转出腕视野或与抓取 rz 纠缠。
- 夹爪在接近阶段误动作、开合极性/开度与现场不一致时，会出现「到位不夹」或「一开始就合上」。

### 本版目标

- 明确 **观测姿态** 与 **抓取姿态** 分工，保证腕精成像与 tip 竖直夹取可复现。
- 抓取 XY 以腕精板心为 tip 目标，避免手眼偏置下的增量纠偏偏心。
- 参数与 `config/grasp_config.yaml`、当前 `pipeline.run_live` 行为对齐，便于复现与评审。

### 约束与适用场景

- 适用：与当前实验一致的小板板型、左臂 A、知行夹爪、Gemini305 腕相机、示教 tip 高度附近的承载。
- 不包含：提起、搬运、放置；大板双臂对夹；跨板型自动泛化。
- 假设：头/腕手眼与模板方向正确；portal 头腕流可用；RIM 运控与知行夹爪通信正常。

### 范围边界

| 包含 | 不包含 |
|------|--------|
| 头粗定、camera-down 悬停、腕精、板心对齐、降 Z、收夹 | 完整 pick-and-place |
| 小板单臂 A | 大板 / 托盘夹取（另案） |
| 配置与代码路径索引 | 新标定流程本身（仅引用已有标定结果） |

### 指标性质说明

下列数值多为 **配置目标/示教值**，不是本版已统计的长期成功率或绝对定位精度。早期 001～008 实验验证的是旧姿态口径下的链路，**不能直接当作本版验收通过证据**。

## 3. 本版方案设计

### 3.1 总体流程

```
头双目静止采图 → YOLO-Pose 粗定（多帧中值 + board ID）
        ↓
粗定位悬停：腕相机光轴竖直向下，光心约板上方 hover_height；rz 保持接近前当前值
        ↓
静止 → 腕多帧精定（Pose + 外轮廓匹配，匹配粗 ID）
        ↓
张开夹爪 → 同高：tip XY=板心，rpy=(-90°, 0, rz)
        ↓
降到 grasp_z_m + grasp_z_lift_m → 静止 → 收夹 → 停止
```

UI：`识别抓取点`（plan_only，不动臂）→ `执行抓取`；`stage=coarse` 只做到悬停。

### 3.2 模块职责

| 模块 | 输入 | 处理职责 | 输出 | 关键约束 |
|------|------|----------|------|----------|
| 头粗定位 | 头左右图、FFS 深度、`T_base_cam` | YOLO-Pose 3cls 检板；多帧中值；赋 board ID；选目标小板 | 基座板心/角点/粗 rz、目标 ID | 只选小板；nopcb 不抓；悬停不用板边 rz |
| 粗悬停运动 | 粗板心、当前法兰 rz、`T_tool_cam` | 计算 camera-down 法兰位姿；`move_line` 接近 | 悬停位姿；腕视野内目标 | keep_rz；\|err_xy\|过大则中止 |
| 腕精定位 | 腕 RGB-D、EE、粗板列表 | Pose + shape_match；ID 匹配；rz unwrap | `ObjectPose` 板心 XY、rz | 需粗板列表；深度失败有 fallback |
| 抓取位姿 | 腕精结果、示教 Z、lift | 板心 + (-90,0,rz)；再生成下降位 | orient / descend 法兰指令 | tip XY=板心，tcp_offset=0 |
| 夹爪 | 开合指令 | 抓前开、到位后以配置开度收 | 夹持状态 | 知行极性：0 闭 1 开 |
| 静止门控 | 法兰反馈 | settle + still 判据后再采图/收夹 | 稳定 EE | 容差非视觉精度 |

### 3.3 姿态分工（设计要点）

| 阶段 | 姿态 | 说明 |
|------|------|------|
| 观测悬停 | camera-down | 腕相机光轴竖直向下；305 侧装时 tip 可近水平 |
| 抓取 | end-down | `rx=-90°, ry=0, rz=腕精(经 offset/unwrap)`；tip 竖直向下对准板心 |

粗悬停 **不** 将板边 rz 写入法兰，避免观测与对齐耦合。

### 3.4 抓取位姿生成

转换链路：匹配中心像素 + 深度 → 腕相机三维 → `T_tool_cam` → 采图时 EE → 基座板心 `(fine.x, fine.y)` + rz。

| 量 | 本版规则 |
|----|----------|
| XY | tip XY = 板心；禁止用「camera-down 法兰 +(fine−coarse)」做增量纠偏（手眼偏置易偏心） |
| rpy | (-90°, 0, rz)；`tool_rz_offset_rad=π/2`；相对粗 rz `nearest_rz` unwrap |
| Z | 先同高完成板心+end-down，再降到示教 tip Z + lift |

### 3.5 关键参数

| 参数 | 本版取值 | 用途 | 取值依据 / 待验证点 |
|------|----------|------|---------------------|
| `hover_height_m` | 0.30 m | 相机光心相对板面高度 | 现场可看清小板；待补不同高度成像对比 |
| `hover_camera_down` | true | 悬停用相机朝下 | 测试中腕精需要；与 tip-down 观测对比后采用 |
| `n_frames` | 5 | 头/腕多帧 | 相对旧文档 10 帧下调；稳定性待系统统计 |
| `settle_s` | 1.0 s | 到位后再识别/收夹 | 现场抖动；与吞吐折中 |
| `grasp_z_m` | 0.70548 m | tip 贴板示教高度 | `config/grasp_z.json` / 2026-11-10 左臂示教 |
| `grasp_z_lift_m` | 0.01 m | 防压板上抬 | 测试中防压；是否 5/10 mm 最优待补样本 |
| `gripper.grasp_position` | 0.4 | 收夹开度 | 略留缝夹板；物理开口未标定 |
| `tool_rz_offset_rad` | π/2 | 板边角→夹爪 rz | 与 rimbot / 几何约定对齐 |
| `target_board_id` | 2（配置值） | 优先抓取 ID | 现场托盘布局；按任务可改 |
| `board_match_max_dist_m` | 0.12 m | 腕-头 ID 匹配阈值 | 经验值 |
| `shape_match.score_thresh` | 5.2 | 轮廓匹配分数阈 | 沿用旧经验；光照敏感 |
| 复位 rpy | (90°, 0°, 0°) | UI 记复位位时固定姿态 | 只记 XYZ；姿态固定 |

### 3.6 依赖

- 感知：头 portal/FFS、腕 portal RGB-D、YOLO 权重、shape 模板。  
- 标定：`T_base_cam`、`T_tool_cam`、腕内参。  
- 运控：RIM `move_to_pose`；知行夹爪 RS485（`com_ch=2`）。  
- 入口：`pcb_grasp/pipeline.py` · `geometry.py` · `shape_refine.py` · `rim_motion.py`。

### 3.7 异常处理（设计）

| 情况 | 行为 |
|------|------|
| 粗悬停 \|err_xy\| > 80 mm | 中止（coarse 阶段可软失败返回） |
| 腕精失败 / 无深度可用帧 | 抛错中止，可落盘失败腕图 |
| 未设置 `grasp_z_m` | 拒绝下降 |
| 粗板列表缺失 | 腕精拒绝执行（需 ID 匹配） |

设计中的方法以代码已实现为准；长期成功率等能力 **不** 写成已验证指标。

## 4. 与上一版本的差异

前版材料：[PCB 小板视觉定位与抓取方案](https://airimbot.feishu.cn/wiki/ZGraw4rF0iah7Vk7ytBccEY3njg)（2026-11-09）。

| 变更项 | 前版设计 | 本版设计 | 变更原因 | 影响范围 |
|--------|----------|----------|----------|----------|
| 悬停姿态 | 工具朝下 + Y/Z 额外让位；法兰 Z≈粗 Z+450 mm | camera-down；光心上方 0.30 m；无额外 Y/Z 让位 | 腕精观测需要相机朝下；旧高度口径过时 | 接近轨迹、腕成像 |
| 粗定位 rz | 文档未强调 keep；实践中易与板边对齐耦合 | 悬停 **keep 当前 rz**，不转板边 | 减少视野丢失与 rz 纠缠 | 粗接近、后续 unwrap |
| 抓取姿态 | 「保持已验证朝下」；精定位后调 XY/rz 再降 | 明确 **(-90°,0,rz)**；先板心对齐再降 Z | tip-down 与 camera-down 混淆导致运动异常 | 精→抓运动段 |
| 抓取 XY | 腕精 XY + 既有转换 | tip XY=板心；禁用 cam-down 法兰增量 | 手眼偏置致偏心 | 对中精度 |
| TCP / 示教 Z | 法兰示教 −227.26 mm | tip=`linkTCP`；`grasp_z_m=0.70548` + lift 10 mm | TCP 定义变更 | 下降高度、压板风险 |
| 腕相机 | D405 | Gemini305 portal | 硬件更换 | 内参/手眼/深度尺度 |
| 夹爪时序 | 文档写闭合至 0.41；未强调接近不动爪 | 接近不动爪；抓前开、到位后 0.4 收 | 误闭合/不夹问题 | 抓取可靠性 |
| 多帧 / settle | 10 帧；settle 0.6 s 等 | 5 帧；settle 1.0 s | 吞吐与稳定折中 | 节拍、抗抖 |
| 复位姿态 | 未作为方案要点 | 记复位只存 XYZ，rpy 固定 (90,0,0) | UI 复位一致性 | 操作流程 |

保留未改动的核心：头粗 + 腕精两阶段；Pose 关键点定初向 + 外轮廓匹配；示教高度抓取（口径更新）；本阶段收夹后停止、不做搬运。

## 5. 关键决策与取舍

| 决策点 | 采用方案 | 依据 | 代价 / 限制 | 待确认项 |
|--------|----------|------|-------------|----------|
| 观测 vs 抓取姿态分离 | 悬停 camera-down，抓取 (-90,0,rz) | 真机：同一姿态难以兼顾腕图与竖直夹取 | 多一次翻姿态运动；路径需可规划 | 翻姿态失败率、最短路径 |
| 粗悬停 rz | keep 当前，不转板边 | 转 rz 易丢目标 / 与精 rz 冲突 | 悬停时夹爪不一定平行板边 | 极端初始 rz 是否仍可见板 |
| 抓取 XY | 直接板心，非粗→精法兰增量 | 增量受手眼偏置影响，实测易偏心 | 依赖腕精绝对 XY 质量 | 多板位偏心统计 |
| 下降高度 | 示教 tip + 10 mm lift | 贴板示教 + 防压 | 抬太高可能夹不实 | lift 最优值 |
| 收夹开度 | 0.4 | 现场略留缝 | 未映射物理开口 | 不同板厚适应性 |
| 多帧数 | 5 | 相对 10 帧降耗时 | 野值抑制变弱可能 | 与 10 帧误差对比 |

未列入材料中未讨论过的备选（不编造评审历史）。分析性建议见第 8 节，不作为已拍板里程碑。

## 7. 风险、依赖与迁移事项

| 类型 | 内容 |
|------|------|
| 技术风险 | camera-down→end-down 翻姿态 IK/扫掠；rz ±180° 残留；轮廓匹配受光照/反光；lift 与夹实权衡 |

| 迁移 | 使用本版：更新/确认 `grasp_config.yaml`、`grasp_z.json`、305 手眼与内参；UI 走 `pcb_grasp` |
| 旧版保留 | 前版飞书页保留作历史；不自动覆盖 |
